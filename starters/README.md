# Заготовки к лабораторным работам

Здесь лежат каркасы к трём самым объёмным работам курса — №7, №9 и №10.
Заготовка снимает рутину (импорты, скелет экрана, временную модель) и
оставляет вам то, ради чего работа задумана.

## Как пользоваться

1. Скопируйте нужный файл в свой проект:

   ```
   mkdir -p lib/starters
   cp starters/lab09_starter.dart lib/starters/
   ```

2. Запустите его **до того, как написали хоть строчку**:

   ```
   flutter run -t lib/starters/lab09_starter.dart
   ```

   Приложение соберётся и откроется. На месте невыполненных частей
   вы увидите серые прямоугольники `TODO: ...` — это заглушки.

3. Выполняйте помеченные `// TODO` места **по одному**, каждый раз
   нажимая `r` (горячая перезагрузка) и проверяя результат на экране.
   Номера TODO совпадают с номерами заданий в методичке: `TODO 3.2` —
   это второй шаг задания 3.

4. Когда всё заработало, **перенесите классы в постоянные файлы**
   проекта — в шапке каждой заготовки написано, что куда. Файл из
   `lib/starters/` после этого удалите: в итоговое приложение он
   не входит.

## Что важно понимать

* Заготовка — не образец для сдачи. Сдаётся ваш проект, а не
  запускаемый файл из `lib/starters/`.
* Временный класс `Book` внутри заготовки нужен только для запуска.
  Замените его на свой из ЛР №3 — в этом половина смысла упражнения.
* Виджет `NotDoneYet` удаляется вместе с последней заглушкой.
* Задания, помеченные в методичке как «дополнительно», в заготовке
  тоже отмечены — их TODO можно пропустить.

| `lab07_starter.dart` | №7. Вёрстка, темы, адаптивность | карточка книги, экран деталей, тема |
| `lab09_starter.dart` | №9. Списки, анимация, рисование | `ListView.builder`, `Dismissible`, `CustomPainter` |
